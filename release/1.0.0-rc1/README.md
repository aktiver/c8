# RC1 release directory

`release-spec.yaml` is the immutable policy. `support-matrix.yaml` is deliberately unqualified until exact live provider versions and evidence are retained. `ACCEPTANCE_TEST_PLAN.md` is the final acceptance procedure, and `KNOWN_ISSUES.md` lists current publication blockers. Generated freeze, prerequisite, artifact, supply-chain, reproducibility, and publication-certificate files belong in this directory but must not be created from static or synthetic evidence.
