# Phase 40.13.16 — complete online distributed SPARQL execution lane

Phase 40.13.16 activates the complete typed SPARQL algebra for ordinary `/sparql` and `/query`
requests. Existing native Arrow/shuffle kernels remain the preferred path for certified graph-local
joins. Every deterministic, non-federated legal query is sent as a checksum-bound original and
rewritten algebra pair to a bounded set of distinct fragment-worker pods. Each worker executes the
pinned scalar oracle against the exact active dataset and returns a canonical result checksum plus
the full typed result.

The coordinator requires the dense replica set, distinct worker identities, identical snapshot and
dataset hashes, and exact canonical-result equality. Ordered results must also have the identical
sequence; unordered SELECT replicas may legally return the same bag in different row order. A timeout, missing
replica, duplicate worker, authorization change, checksum mismatch, or semantic difference aborts
the request without returning partial data. This covers SELECT bags and ordering, ASK booleans, and
RDFC-canonical CONSTRUCT/DESCRIBE graphs without substituting SQL null or collation behavior.

Queries containing query-scoped volatile functions (`RAND`, `NOW`, `UUID`, `STRUUID`, or `BNODE`)
remain on the bounded uncached scalar lane because independently rerunning them for equivalence
would change their legal result. Secured remote `SERVICE` execution remains Phase 40.13.18 scope.

The Kubernetes fragment pool uses Guaranteed-QoS resource requests, one cgroup-aware Rust thread
budget, and single-threaded OpenMP/BLAS inside each asynchronous worker. Query replicas are charged
to the existing algebra/shuffle admission class, so backlog, active spill, CPU, and memory signals
drive the fragment HPA and cluster node provisioning. Replica count is stable for one request even
when pods or nodes scale during execution.

This phase does not implement ontology alignment, schema matching, or raw-data mapping. It also does
not declare release qualification: native Rust, live Helm/Kubernetes, fault injection, and the full
multinode scalar-differential corpus must pass in the designated builder and cluster.
