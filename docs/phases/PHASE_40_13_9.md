# Phase 40.13.9 — distributed SPARQL property-path foundation

Phase 40.13.9 compiles every typed SPARQL 1.1 property-path occurrence into a checksum-bound
Thompson NFA. The compiler preserves sequence order, alternative, inverse direction, negated
property sets and the exact zero/one/arbitrary-length operators. It records graph scope, endpoint
patterns, stable partition count, iteration/frontier/visited/checkpoint/spill ceilings, hot-vertex
thresholds and the mandatory scalar-equivalence gate.

Runtime state is `(origin entity, current entity, automaton state)`. Keeping the origin prevents
frontiers from different input bindings from collapsing. Endpoint results use set semantics, so
multiple physical routes between the same subject/object pair do not create duplicate path matches.
The zero-length branch of `?` and `*` is represented by epsilon closure rather than a synthetic RDF
edge.

Each frontier key has a stable hash owner independent of replica count. Vertices above the configured
adjacency threshold split into deterministic edge subranges, allowing bounded concurrent processing
across Rust worker lanes and anti-affine fragment pods. A coordinator advances only after the exact
expected work identities return complete, checksum-valid results. Missing, duplicated, foreign or
partial sub-work fails closed. A traversal terminates only when that complete merge produces no new
globally unvisited state.

Every completed iteration produces a canonical bounded checkpoint containing the visited set, next
frontier, endpoints, iteration and query/plan/path/automaton identities. The checkpoint SHA makes
retry or pod replacement deterministic. The checkpoint ceiling fits the path spill ceiling, which in
turn fits the existing marker-owned local-NVMe shuffle-spill budget; local spill remains acceleration
state, never semantic truth.

The fragment HPA observes pending path work and active frontier size. The query HPA observes
checkpoint pressure. CPU and memory targets, cgroup-aware Rust lanes, one-thread OpenMP/BLAS settings,
Guaranteed QoS, anti-affinity and the RKE2 node-autoscaler contract remain unchanged.

This source increment does not enable the online distributed property-path lane. Native compilation,
worker transport, authorized adjacency-index integration, W3C/scalar differential equality, failure
injection, checkpoint-resume and live multinode autoscaling are blocking gates. Until then, the
qualified scalar evaluator remains authoritative.

Ontology alignment and raw-data mapping are absent from this database workstream.
