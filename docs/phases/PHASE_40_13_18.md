# Phase 40.13.18 — secured federation and SPARQL Protocol

## Runtime boundary

This phase enables SPARQL 1.1 `SERVICE` and `SERVICE SILENT` through the same typed scalar algebra
used by ordinary `/sparql` and `/query` requests. Fixed endpoint IRIs and endpoint variables are
legal only when the resolved IRI exactly matches a checksum-bound registry entry authorized for
the authenticated tenant. Remote state is
never inserted into the local dataset, ontology assembly, closure, provenance, snapshot
certificate, or query-result cache.

The registry contains endpoint IRIs, ceilings, and optional environment-variable names for bearer
tokens. It never contains credential values. Registry and credential Secrets are mounted
separately; the registry bytes must match their configured SHA-256 before the query pod becomes
ready.

## Network and failure safety

- Production endpoints require HTTPS and cannot contain userinfo or fragments.
- Every call resolves DNS, rejects private, loopback, link-local, multicast, documentation, and
  reserved addresses, then pins the validated address into the TLS client connection.
- Redirects are disabled, preventing an allowlisted public endpoint from redirecting to an
  untrusted target.
- Connection, request, queue, response-byte, per-query call, process concurrency, and pending-call
  ceilings are enforced before results enter the evaluator.
- Non-silent errors fail the whole query. The standards evaluator alone applies `SERVICE SILENT`
  identity semantics; an error is never converted to an empty successful remote relation by the
  HTTP layer.
- Successful enriched responses contain checksum-bound registry, endpoint-set, call-count, byte,
  and completion evidence.

## HPC and Kubernetes behavior

Concurrent queries share a bounded outbound lane pool sized inside the pod's cgroup-aware blocking
thread budget. Query StatefulSet replicas distribute independent federated requests across nodes.
The query HPA observes federation pending calls in addition to admission backlog, CPU, memory, and
property-path checkpoint pressure. A dedicated egress NetworkPolicy admits TCP 443 only to
operator-supplied federation CIDRs; the default remains deny.

Scaling changes capacity only. Endpoint allowlists, result semantics, and failure behavior are
unchanged by pod count. Query coordinators retain a positive minimum replica count; federation is
disabled by default until both the registry Secret and its checksum are configured.

## OWL boundary

Local authorized asserted `https://c8-next-generation.io/*/*/semkg` graphs can still be evaluated
through exact HermiT BGP substitution. A BGP inside a remote SERVICE is evaluated by that endpoint
under its advertised semantics and is not assembled into the local ontology. This phase adds no
ontology alignment, source-to-ontology mapping, schema matching, or raw-data transformation.

## Qualification boundary

Source contracts, registry schema, OpenAPI evidence, network policy, HPA wiring, and inherited
static gates are executable in this candidate. Native Rust tests, official federated-query tests,
Helm render/lint, redirect/DNS/timeout fault injection, and live multinode HPA/cluster-autoscaler
tests remain release gates when their toolchains and infrastructure are available.
