# Phase 40.13.5 — Zero-failure scalar SPARQL oracle

Phase 40.13.5 closes the twelve pinned SPARQL 1.1 query/result failures carried
by Phase 40.13.4. It adds a workspace-pinned evaluator compatibility layer for
aggregate, graph scope, `BNODE`, `MINUS`, property-path identity, and lossless
RDF term semantics.

The phase gate requires all 338 executable tests from the pinned SPARQL 1.1
query and result manifests to pass. It also requires native regressions, the
locked offline Rust workspace, one nested native thread per conformance child,
and unchanged HPC/admission/autoscaling contracts.

This is a scalar-oracle milestone. The feature matrix remains an inventory
because distributed algebra, online exact HermiT entailment, secured federation,
protocol/service-description behavior, and live multinode Kubernetes scaling
are separately qualified workstreams. A green scalar suite must not activate a
full-SPARQL or production service-description claim.

Ontology alignment is absent and out of scope.
