# Phase 40.13.23 benchmark inputs

`qualification-inventory.yaml` defines the minimum release matrix and claim gates. A real run must supply three content-addressed enterprise datasets, exact release-image digests, an observed hardware/NUMA profile, a dated pricing profile, and a completed Phase 40.13.20 live autoscaling report. The plan builder rejects missing or non-digest identities.

Apache Jena is an optional external competitor process for the applicable SPARQL and property-path scenarios. It is not a Cargo dependency, NGKG container layer, sidecar, service, or fallback runtime. NGKG execution under test is exclusively the Rust release images.

Each capacity group repeats the identical operation and expected semantic result at increasing node/CPU/RAM points. Every warm-up is retained and tagged. Every measured trial is used; failed trials, slow trials, timeouts, partial results, and node-loss retries cannot be removed from evidence.
